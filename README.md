# Version Control Assignment 1

This is a simple portfolio website created for practicing Git and GitHub.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features

- Simple portfolio page
- About section
- Skills section
- Projects section
- Contact section
- JavaScript button interaction

## Assignment Objectives

This assignment demonstrates:

- Creating a local Git repository
- Making commits
- Creating branches
- Merging branches
- Resolving merge conflicts
- Pushing the project to GitHub
